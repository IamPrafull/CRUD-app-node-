# CRUD App 🚀

A simple CRUD (Create, Read, Update, Delete) application built while learning backend development with Node.js, Express.js, MongoDB and EJS.

This project allows users to create, view, update and delete user records.

---

## 📌 Features

- ✅ Create new users
- ✅ Display all users
- ✅ Update existing user details
- ✅ Delete users
- ✅ Server-side rendering using EJS
- ✅ MongoDB database integration

---

## 🛠️ Tech Stack

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Frontend
- EJS
- HTML
- Tailwind CSS

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/IamPrafull/CRUD-app-node-
```

### 2. Navigate into project folder

```bash
cd CRUD-app-node-
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
node crudapp.js
```

The application will start running at:

```
http://localhost:3000
```

## 🔄 CRUD Operations
